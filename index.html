音楽教室 FUN HOUSE / Vocal school FUN HOUSE
利用規約

本規約は、音楽教室 FUN HOUSE / Vocal school FUN HOUSE（以下「当教室」）が提供する各種レッスンの受講に関する条件を定めるものです。受講生（未成年の場合はその保護者。以下「会員等」）は、本規約に同意のうえご利用いただくものとします。

第1条（適用範囲およびお申し込み）
1. 本規約は、当教室のレッスン受講生（スクール会員）に適用されます。
2. ご入会時には、氏名・住所・電話番号等の正確な情報をご申請いただきます。ご提供いただいた情報は、教室運営（連絡・案内・管理等）に該当する事項にのみ使用いたします。
3. 当教室では入会金は頂いておりません。未成年者がご利用される場合は、保護者の同意を必須とします。

第2条（施設・備品の取り扱いおよび事故防止）
1. 施設内の楽器、音響機材、設備、備品は丁寧に取り扱い、使用後は元の位置・状態に戻してください。
2. グランドピアノ・アップライトピアノ等の精密な楽器の上には、事故防止のため飲食物や水滴のついた容器等を置くことを固く禁止いたします。
3. 施設内・敷地内は全面禁煙（電子タバコ等含む）です。

第3条（禁止事項および退会処分）
会員等は、施設内において以下の行為を行ってはならないものとします。
1. 迷惑行為：他の会員、講師、スタッフ等への暴言、ハラスメント、勧誘、営業活動、無断撮影・無断録音行為。
2. 酒気帯び・危険物：敷地内での飲酒、酒気を帯びた状態での利用、危険物の持ち込み。
3. 妨害・損害：レッスン進行の著しい妨害、大音量・振動による周辺への迷惑行為、設備・備品の意図的または不注意による破損・汚損行為。
4. 秩序の混乱：その他、教室の秩序や運営を乱す一切の行為。
上記のような行為が見受けられる場合、運営に支障をきたすと判断した場合、または再三の注意にも関わらず改善が見られない場合は、退会をお願いすることがございます。

第4条（免責・損害賠償および復旧費用の請求）
1. 貴重品管理・事故：敷地内での所持品・貴重品の紛失、盗難、破損、ならびに利用者の過失・不注意による事故や怪我について、当教室は一切の責任を負いかねます。
2. 設備・楽器の破損賠償：会員等の故意または不注意（禁止行為を含む）により、設備・備品・楽器等を破損・汚損させた場合、その修繕費・購入費等の実費全額を請求いたします。
3. ピアノ等の汚損・故障に関する特別規定：グランドピアノおよびアップライトピアノの上に飲食物（水分・液体含む）を置いたこと、またはこぼしたことにより生じた破損・不具合・汚損については、原因となった会員等に対し、クリーニング・修理費用等の実費全額、ならびに修繕期間中に発生するスタジオ利用料金の全額（営業補償）を請求いたします。
レッスン・月謝
第5条（お月謝および支払い方法）
1. 支払い方法：お月謝（月会費）は、会員管理システム「hacomono」を通じたオンライン口座振替（毎月自動引き落とし）にてお支払いいただきます。
2. 引落日（決済日）：毎月27日に翌月分のお月謝が引き落とされます（前払い制）。※27日が土日祝日の場合は、翌営業日の引き落としとなります。
3. 初回および入会時の引き落としルール：入会手続き完了日（hacomono登録・初回レッスン開始日等）により、初回のお支払いタイミングおよび対象期間が異なります。
【入会日が1日〜10日の場合】入会当月27日に「当月分・翌月分（2ヶ月分）」の会費を引落。翌月27日より通常通り翌々月分を前払い引落。
【入会日が11日〜末日の場合】入会翌月27日に「当月分・翌月分・翌々月分（3ヶ月分）」の会費をまとめて引落。翌々月27日より通常通り前払い引落。
4. 教材費：お月謝以外に教材費が発生する場合は、講師と相談のうえで購入となります。
5. 返金不可：既にお支払いいただいた受講料（引き落とし完了分）および教材費等は、当教室の責に帰すべき事由がある場合を除き、いかなる理由であっても返金いたしかねます。

第6条（レッスン時間およびレッスンルーム）
1. レッスン時間：全てのコースにおいて、レッスン時間の長さは入退室や楽器の準備、片付け等も含めた時間となります。
2. ルーム指定：お部屋の割り当てを調整しておりますので、レッスンルームの指定は出来ません。

第7条（レッスンの振替・キャンセル・休講）
1. 振替条件：レッスンの振替は、前日の21時までにお申し出いただくことでお受けできます。
2. 振替回数：レッスンの振替は原則として当月内1回までとなります（月末レッスンの振替希望に限り、翌月へ振替可能）。
3. 当日・無断キャンセル：レッスン当日のキャンセルおよび無断キャンセルにつきましては、1回のレッスン消化扱いとなります。
4. 災害時の対応：台風や地震等の災害発生時、教室の判断にて休講とした場合は振替を行います。
退会・会員特典
第8条（退会・休会）
1. 申出期限：退会や休会をご希望の方は、レッスン受講最終月の2ヶ月前の末日までにお申し出ください。（例：9月から退会・休会希望の場合、7月末日までにご連絡）
2. 提出方法：必ず公式LINEにてご連絡ください。期限を過ぎてのお申し出の場合、翌月以降のお月謝が発生いたします。

第9条（スクール会員特典）
1. スケジュール調整：レッスンの曜日・時間は原則固定にしておりません。ご都合に合わせて柔軟に調整可能です。
2. 複数種目の受講：2種目以上の楽器を同時に習うことが可能です。
3. 練習室の無料利用：レッスン当日に限り、空いている教室を事前練習やおさらいに無料でご利用いただけます（※ただし、有料でご予約されるレンタルスタジオ利用者がいらっしゃる場合はご退出いただきます）。
4. 楽器レンタル：ヴァイオリン・ヴィオラの生徒様は、レッスン毎に1回300円にて楽器をレンタル可能です。
